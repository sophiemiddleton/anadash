About This Analysis

This dashboard presents results from the Mu2e charged lepton flavor violation (CLFV) analysis, focusing on muon-to-electron conversion (μ⁻ → e⁻). The analysis optimizes track quality cuts, detector veto conditions, and momentum/time windows to maximize signal sensitivity while minimizing background contamination. Results are displayed using the latest MDS3a Monte Carlo sample.
