This dashboard displays the latest analysis outputs from the pyCount directory.

The Mu2e experiment searches for charged-lepton flavor violating (CLFV) conversions of muons to electrons in the nuclear field. This process is heavily suppressed in the Standard Model but predicted by many beyond-Standard-Model theories. The experiment aims to achieve unprecedented sensitivity to the muon-to-electron conversion process.

Physics Background: The primary backgrounds to the signal are cosmic-ray-induced backgrounds, beam-related backgrounds (DIO - Decay In Orbit, RPC - Radiative Pion Capture) backgrounds. This analysis implements a comprehensive cut strategy to suppress these backgrounds while maintaining high signal efficiency for the Ce conversion signature.

Analysis Purpose: This reference analysis optimizes event selection cuts to achieve the best signal sensitivity by tuning the trade-off between signal efficiency and background rejection. The dashboard displays:

  • Sensitivity Results: Branching fraction upper limits and required signal for discovery significance
  • Cut Statistics: Event counts and efficiencies at each selection stage from cut_stats.csv
  • Optimization Plots: Selection optimization curves showing signal vs. background rejection (*_selection.png)
  • Distribution Plots: Reconstructed momentum and time distributions for signal and background processes
